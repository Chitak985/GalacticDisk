The ExampleConfig.txt adds a large galaxy at Eeloo and is used as an example. To see the galaxy for yourself, rename the file to .cfg.

ExampleVolumetricConfig.txt demonstrates the new particle-free volumetric renderer.
Rename it to .cfg instead of enabling the particle example for the same body.
Keep Assets/galacticdisk-windows.bundle alongside GalacticDisk.dll for Windows volumetric rendering.
The toolbar can select Particles or Volumetric and load a Milky Way preset.
See Volumetric.md for the new parameters, building instructions, and testing limitations.

ExampleRingConfig.txt demonstrates GalacticDiskRingDefinition with particle or volumetric rendering.
Rename it to .cfg and choose a planet to enable the ring. See Rings.md for the parameters.
