The folder this file is in should be put in GameData to install the mod.

The source code is at https://github.com/Chitak985/GalacticDisk. For any questions, ask @chitak985 on discord. You can easily find me in various KSP servers or in my server here: https://discord.gg/qgdEU2X6Xj

The ExampleConfig.txt adds a tiny galaxy at Eeloo and is used as an example. To see the galaxy for yourself, rename the file to .cfg.

ExampleVolumetricConfig.txt adds a tiny galaxy that uses the new volumetric renderer, also at Eeloo. Rename to .cfg to see it.

ExampleRingConfig.txt adds a large volumetric ring at Eeloo, rename to .cfg to see it.
